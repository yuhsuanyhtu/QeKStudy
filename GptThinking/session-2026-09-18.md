## 2. Git 能否做前後端 / Can Git support frontend and backend?

### User / 使用者
git 可以做有前端後端的嗎

### Assistant / 助理
Git 本身只負責版本控制，不會執行後端。GitHub 可以儲存前端與後端程式碼，但 GitHub Pages 只能直接託管靜態前端。

完整的零成本前後端架構可由 GitHub 儲存程式碼，前端部署到 Cloudflare Pages 或其他免費平台，後端使用 Cloudflare Workers、Vercel Functions、Supabase 或 Firebase，資料庫則使用 Supabase 或 Firebase。

**English summary:**  
Git is a version-control system, not a backend runtime. GitHub can store both frontend and backend code, while GitHub Pages only directly hosts static frontend content. A full-stack application can still use GitHub as the source repository while deploying frontend and backend components to free hosting/runtime services.

## 9. TeenageStudyTool 的設計緣由 / Design rationale discovered in TeenageStudyTool

### User / 使用者
你看一下teenagestudy 那個repo 裡面我有請之前幫忙做的AI把一些緣由寫下來

### Assistant / 助理
檢查 `TeenageStudyTool` 的 notes、README 與 commit history 後，找到多個重要背景：

- 曾因 QeK 做錯一題就關瀏覽器，而加入 abandoned attempt 紀錄；目的不是只看成績，而是理解嘗試、挫折與退出的位置。
- Reward 機制的目的不是單純「答題換錢」，而是讓學生設定目標、完成目標並理解差距。
- 沒拿到獎勵時，也應告訴學生差多少、下一步怎麼進步。
- 技術行為不應讓學生誤以為成果突然歸零。
- 家長端必須能調整、補正與核准，不應被演算法綁死。
- 老師的教學回饋曾直接形成新題型。
- QeK 本人後期也主動要求更多題目與更高挑戰。
- 效能改善也曾直接源自孩子回饋「速度慢、越來越慢」。

因此決定 QeKStudy 應先建立 Product Origin / Product Principles，再繼續展開 BDD。

**English summary:**  
Reviewing TeenageStudyTool revealed that many design choices were rooted in real behavior and feedback: abandonment after mistakes, self-prediction, supportive feedback, preserving perceived progress, parental correction authority, teacher-driven question types, QeK's own request for more challenge, and performance complaints from actual use. These findings motivate documenting product origin before expanding BDD.

### Assistant / 助理
這四點被整理為 QeKStudy 的正式重寫動機：

1. 系統使用範圍從單一家庭擴展到班級，因此多人、多家庭與權限隔離需要成為正式需求。
2. 老師建議增加刷題量，而 QeK 本人也希望更多題目與挑戰，但題量增加不能單純拉長每一回合而提高退出風險。
3. 為長期會考準備，需要依年級與已學進度逐步加入會考型題目，向下整合舊知識；答錯時提供回頭查找與複習的方向，而不只是顯示正解。
4. QeKStudy 從一開始就定位為跨科系統，而不是英文工具外加其他科目。

這些內容已另存為 `GptThinking/PRODUCT_ORIGIN.md`。

**English summary:**  
The rewrite is driven by class-wide exposure, increased practice demand from both teacher and student, long-term cumulative CAP preparation with guided remediation, and the need to support multiple subjects from the beginning.
